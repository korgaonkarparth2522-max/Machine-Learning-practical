# Machine Learning Practicals

This repository contains my Machine Learning practical experiments implemented using Python and Google Colab.

## Experiments

### Experiment 1 – Titanic Dataset
- Data loading and inspection
- Data cleaning and handling missing values
- Data manipulation
- Data visualization using Matplotlib and Seaborn

### Experiment 2 – Simple Linear Regression
- Auto MPG dataset
- Predicting MPG from Horsepower
- Ordinary Least Squares (OLS)
- SSE, MSE and R² evaluation
- Regression and residual plots

### Experiment 3 – Multiple Linear Regression
- CarDekho used-car dataset
- Predicting car selling price
- Categorical data encoding
- Feature standardization
- Multiple Linear Regression using OLS
- RSS and R² evaluation
- Model performance visualization
